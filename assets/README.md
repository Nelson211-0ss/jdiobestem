# Source assets

Originals that the app does not ship, kept because they exist nowhere else.

## fonts-source/

The font families the site uses, as supplied. `frontend/app/fonts/` holds only
the subset `.woff2` files the browser loads; these archives hold the full
families — every weight, the italics, and the `.ttf`/`.eot` formats — including
faces the site does not currently use.

Vistol Sans is a licensed family. Do not delete these without knowing where
another copy is.
